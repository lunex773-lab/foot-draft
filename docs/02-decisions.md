## 2. 実装上の判断（仕様の範囲内で決めたもの）

| 項目 | 内容 | 理由 |
| --- | --- | --- |
| 空席の扱い | ホストはいつでも開始でき、空席はCPUが埋める。4人そろうと自動で開始 | 1人でもテストできる。仕様の「最大4人」に合う |
| 切断中のプレイヤー | ドラフトでは時間切れで自動指名（設計書 3-5）。再接続すると最新の状態を受け取る | 設計書 23-1「通信切断後に復帰できる」 |
| GK の表示能力 | 設計書 4-1 どおり、GK も PAC〜PHY の6項目。値はデータベースのとおり | 確定仕様のとおり |
| 表示能力・OVR | データベースの値をそのまま使う（内部能力から計算しない） | 設計書 4-2「算出してもよい」の範囲。データを正とするため |
| ポジション別評価 | 主ポジションでの評価＝カードのOVR。他のポジションは内部能力から計算した比率と適性外の減点で決める | カードのOVRと編成画面の数字をそろえるため |
| SIM の能力の水準 | SIM は内部能力の「形」（得意・不得意の比率）を使い、全体の水準はカードのOVRに合わせる（補正係数は 0.67〜1.13） | データの内部能力はOVRより平均8%高く、選手ごとのずれも大きい。そのままだとOVRと強さが一致せず、得点も多すぎた（1試合4.2点） |
