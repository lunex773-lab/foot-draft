# SHOOT GACHA（仕様書「SHOOT GACHA IMPLEMENTATION SPEC」）

ガシャを引くと、一人称の PK でシュートしてゴールを決め、選手カードが登場する 3D の演出。
決定事項は `docs/02-decisions.md` の 86〜93（無償 GEMS は 86・87）。

## 1. 抽選と演出の分離（仕様書 6・9）

1. 「引く」を押すと、今までどおりサーバーが抽選し、通貨を引き落とし、天井・カード・強化・交換ポイントを確定する（`POST /api/gacha/draw`、変更なし）。
2. 確定した結果を受け取ってから SHOOT GACHA を始める。演出はその結果を見せるだけ。
3. キーパーの反応・エフェクトの色は、確定した結果のいちばん高いレアリティで決まる（10連は 10 枚のうち最高のもの）。
4. 引っ張る強さ・向きは「足の振り上げ・ボールの速さ・飛ぶ場所」だけを変える。確率・レアリティ・選手は変わらない（クライアントには変える手段がない）。
5. 途中で閉じても、スキップしても、カードはすでに付与済み。

## 2. 操作（仕様書 2）

| 操作 | 動き |
| --- | --- |
| 触れる | 操作開始。ボールの周り（70px 以上）か、ゴールより下（画面の上から36%より下）のどこからでも引ける |
| 下に引く | 引いた量だけ蹴り足（右足）を後ろに振り上げる。体が少し後ろに傾く。狙いの点線とゴールの印が出る。画面の下のほうから引き始めても、画面の下端に届く前に最大の強さになる |
| 左右に引く | 逆の方向を狙う（右下に引くと左上へ）。弱く引くと低く、強く引くと上の隅へ |
| 離す | 軸足（左足）を踏み込み → 蹴り足を振り下ろし → 甲でボールを蹴る → フォロースルー。以後は入力を受け付けない |
| 引きが弱すぎる | 取り消し（元の構えに戻る） |

## 3. キーパーとレアリティ（仕様書 3）

| レアリティ | 反応 | ボールとグローブの距離 | 演出 |
| --- | --- | --- | --- |
| COMMON | 遅れて飛ぶ（0.17秒） | 約0.8m | 白っぽい光 |
| RARE | 素早く飛ぶ（0.05秒） | 約0.4m | 青い光 |
| EPIC | すぐ飛ぶ | 指先がボールに触れる（ボールが少し浮いてそのまま入る） | 紫の光・スローモーション |
| LEGENDARY | 完璧なタイミングで飛び込む | 約0.13m | 金色の光・強いスローモーション |
| ICON | 完璧に飛び込む | 約0.16m | ボールがキーパーの横を通る瞬間に時間が約1.2秒止まり、画面が暗くなり、虹色の輪とクロームの立体文字「ICON」（虹色の縁・光が走る・叩きつけるように登場）。重低音（時間が止まる音・カード登場前の高まり・登場の衝撃音） |

どのレアリティでも必ずゴールに入る。キーパーの飛ぶ位置は、ボールの通る点からグローブの先までの距離が表の値になるようにその場で計算する。

## 4. 3D の内容（仕様書 4）

three.js（0.170.0）で作った本物の 3D。画像ファイルは使わず、テクスチャもすべてコードで描く（実在のクラブ・ブランドは使わない）。

| 部分 | 内容 | ファイル |
| --- | --- | --- |
| スタジアム | 夜の試合。芝（縞・刈り目・凹凸）、ライン、ペナルティアーク、ゴール（7.32m×2.44m・支柱）、LED の広告板（ゲーム名だけ）、3方向の観客席（観客・屋根）、照明塔4本、霧 | `apps/web/src/shoot/stadium.ts`, `textures.ts` |
| ネット | 布のシミュレーション（41×24 の点を Verlet 法でつなぐ）。ボールが当たると膨らんで揺れ、ボールを受け止める。横のネットも張る | `net.ts` |
| 人物 | 自作の体（カプセルの関節モデル）。キッカーは一人称で自分の両足だけが見える（黒のユニフォーム＋ネオンのソックス・黒いスパイク）。キーパーはオレンジのユニフォーム・グローブ | `body.ts`, `kicker.ts`, `keeper.ts` |
| キック | 構え → 引くと振り上げ → 軸足の踏み込み（0.13秒）→ 振り下ろし（膝が最後に伸びる）→ インパクト（0.205秒）→ フォロースルー → 戻り。インパクトの瞬間に甲がボールに当たる位置を計算して体を運ぶ | `kicker.ts` |
| ボール | 重力・カーブ・回転。ゴールラインまでは狙った点を必ず通る軌道、そのあとは物理（ネット・地面との衝突）。光の軌跡 | `engine.ts`, `effects.ts` |
| キーパー | 待機の揺れ → 沈み込み → 横っ飛び（体を伸ばす）→ 着地 | `keeper.ts` |
| カメラ | 一人称（目の高さ・足元のボールを見下ろす）。引くと少し下がり、蹴るとゴールを追ってズーム。キックとネットで小さく揺れる。EPIC 以上はキーパーの横を通る瞬間に寄る | `engine.ts` |
| 光 | トーンマッピング（ACES）、影（ゴール・キーパー・自分の足の影）、ブルーム（照明・エフェクトのにじみ） | `stadium.ts`, `engine.ts` |
| 音 | Web Audio で作った音（観客のざわめき・踏み込み・キック・ネット・歓声・レアリティ別の音）。音声ファイルなし。ICON は重低音（低く下がるサブベース・歪ませた低音の和音・衝撃音・ホールの残響）。音割れしないようにコンプレッサーを通す。スマートフォンのスピーカーでも低音が感じられるように、低音を少し歪ませて倍音を足す | `audio.ts` |

## 5. カード登場（仕様書 5）

ネットに入る → 約1秒後に暗転（0.35秒）→ カードのシルエット（0.65秒）→ 回転（1.15秒）→ カードの絵柄が見える（0.65秒）→ レアリティの演出（光の筋・火花・レアリティ名、ICON は虹色）→ 選手名・ポジション・OVR・6つの能力値・NEW／強化／交換ポイント。

- カードは今までのカード（`PlayerCard`、データベースのカード画像）をそのまま使う。
- ICON のレアリティ名はクロームの立体文字（フォント Orbitron、OFL ライセンス、ゲームに同梱）：`shoot/IconTitle.tsx`
- 10連は1回シュートしたあと、10枚を1枚ずつ登場させる（画面をタップすると早送り）。「まとめて表示」でいつでも結果一覧へ。
- 最後に今までの「抽選結果」の一覧を表示する。

`apps/web/src/shoot/CardReveal.tsx`

## 6. スキップ・音・設定

- 「スキップ」はいつでも押せる（シュート前でも）。押すとカードの登場へ進む。キーボードの Esc も同じ。
- 音はアニメーション中の 🔊 ボタン、または「設定」画面の「サウンド」で消せる（端末に保存）。
- WebGL が使えない端末は、シュートを飛ばしてカードの登場から始める。
- 「動きを減らす」設定（prefers-reduced-motion）の端末では、カード登場の回転・光を控えめにする。

## 8. 確認したこと（仕様書 8）

ブラウザ（Playwright・iPhone 15 の大きさ・ソフトウェア描画）で確認：

- Phase 2〜5：5つのレアリティそれぞれで、構え → 引く（足の振り上げ・狙いの点線）→ 離す（踏み込み・キック）→ ボールの飛行 → キーパーの反応 → ネットの揺れ → カード登場。ICON の時間停止・暗転・虹色
- Phase 6：実際のガシャ画面から Premium 10連（無償 GEMS で支払い）→ シュート → 10枚が順に登場 → 抽選結果の一覧。Standard 1回 → すぐスキップ → カード登場 → 一覧
- コンソールエラーなし

まだ確認していないこと：実際のスマートフォンでの動き（滑らかさ・熱・音）。staging に公開したので、実機で確認してほしい。

## 9. 限界（ユーザー了承済み）

- ブラウザの 3D で自作した人物なので、実写の映像やゲーム機のサッカーゲームほどの見た目にはならない（関節モデルの体）。
- 古い端末では描画が重くなる可能性がある（画面の解像度を最大2倍に制限している）。
