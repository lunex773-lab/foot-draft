# 15. 特殊能力の見直しとレアリティごとの強さ（計画・確認待ち）

2026-11-20 のユーザーの指摘：
- 特殊能力を ICON は2つ、EPIC 以上は1つにし、特殊能力の種類と強さを増やす。
- LEGENDARY が ICON より強いのはおかしい。成長させれば上のレアリティを超えてもよいが、入手した時点で上のレアリティを上回ってはいけない。
- ガシャの重複でカードが強化されるが、具体的に何が強化されるのか。

確認済みの方針（2026-11-20）：COMMON・RARE は特殊能力なし。能力はポジションに合うものを付け直す。OVR は重ならない帯に並べ直す。ICON 専用の能力も作る。

## 1. 重複による強化の中身（今の仕様・決定 70。変更なし）

| 項目 | 内容 |
| --- | --- |
| 強化のしかた | ガシャで持っているカードが出ると自動で +1（最大 +5）。+5 の後の重複は交換ポイント |
| 1段階で上がるもの | OVR +1、カードの6能力値（PAC・SHO・PAS・DRI・DEF・PHY）すべて +1、試合の内部能力（スピード・加速・シュート精度・パワー・決定力・パス・視野・ボール扱い・ドリブル・タックル・インターセプト・ポジショニング・スタミナ・強さ・ジャンプ・GK の各能力）すべて +1（上限 99） |
| 使われる場面 | MATCH（自分のカードのチーム）だけ。DRAFT MATCH では使わない |
| 特殊能力 | 強化では変わらない |

新しい OVR の帯では、+5 まで強化すると1つ上のレアリティの下の方を超えられる（例：LEGENDARY 89 → +5 で 94 ＞ ICON 90）。入手時点では必ず上のレアリティより下。

## 5. OVR の帯（入手時点）

| レアリティ | 今の OVR | 新しい OVR |
| --- | --- | --- |
| COMMON | 45〜65 | **45〜59** |
| RARE | 60〜75 | **60〜69** |
| EPIC | 70〜85 | **70〜79** |
| LEGENDARY | 80〜92 | **80〜89** |
| ICON | 88〜99 | **90〜99** |

変換：同じレアリティの中の順番と差の比率はそのままで、新しい帯にそのまま縮める（今の最低値 → 新しい最低値、今の最高値 → 新しい最高値）。例：LEGENDARY 92 → 89、88 → 86、80 → 80。ICON 88 → 90、99 → 99。EPIC 85 → 79。

OVR が変わった分だけ、カードの6能力値と試合の内部能力も同じだけ動かす（例：OVR −3 なら6能力値・内部能力も −3）。試合の強さは OVR に合わせて計算されるので、入手時点でレアリティが上のカードほど強くなる。

## 6. 作業と影響

| 作業 | 内容 |
| --- | --- |
| データ | 選手データベース（data/player-db-v1）はそのまま残し、読み込む時に「OVR の帯」と「能力の割当表」をかける（変更点がコードで一目で分かる） |
| 試合の計算 | 能力の効果を新しい数値に、新しい8種類・ICON 専用5種類を追加。試合のバランス（勝率・得点）を計算で確認 |
| カード画像 | OVR と6能力値が変わるので、300枚すべて描き直す（実写の250枚は今までどおり、イラストの COMMON 50枚も数字を描き直す。12/1 に実写画像の生成が再開したら実写に置き換え） |
| サーバーのデータ | 本番・staging のデータベースの選手データ（OVR・能力値・内部能力・特殊能力）を更新する移行（migration 0013）。持っているカード・強化の段階・過去の試合の記録はそのまま |
| 画面 | カード詳細の特殊能力の説明を新しい内容に。ICON 専用の能力は印を付ける |
| 試合のバランス | 下のレアリティほど OVR が少し下がる（例：COMMON の最高 65 → 59）。CPU チームは参加者の平均 OVR に合わせて作るので、強さの関係は保たれる |
