# DRAFT MATCH（仕様書 v2.0）

仕様書「FOOTBALL DRAFT — MATCH / DRAFT MATCH SYSTEM UPDATE v2.0」の DRAFT MATCH。
決定事項は `docs/02-decisions.md` の 75〜85（MATCH は 68〜74、`docs/11-match-plan.md`）。

## 1. 流れと状態（仕様書 2・9）

| 状態 | 内容 | 時間 |
| --- | --- | --- |
| WAITING | 1人で相手を待つ | 制限なし（やめられる） |
| MATCHING | 2〜3人そろい、開始を待つ。4人で即開始 | 作成から約60秒（2人目が遅れた時は最低15秒） |
| FORMATION_SELECTION | 各自がフォーメーションを選ぶ（全員が決めるまで他の人には非公開） | 30秒（時間切れは 4-3-3） |
| POOL_GENERATION | 共通カードプールを作る（11×人数＋12枚） | すぐ |
| CHINCHIRO | 全員同時にサイコロ3個を振る（タップ、最大3投）。同じ結果は再勝負 | 1投10秒（時間切れは自動） |
| DRAFT_ORDER | 指名順を発表 | 6秒 |
| PLAYER_DRAFT | スネークドラフト 11ラウンド | 1ピック15秒（時間切れは足りないポジションから自動） |
| TEAM_CONFIRMATION | 配置と戦術を確認・変更（フォーメーション固定、控えなし） | 60秒（2節目以降は30秒） |
| SIMULATION | 90分の自動SIM（結果はサーバーで確定） | 1節60秒の再生 |
| RESULT | 順位・ランキング・報酬を確定 | すぐ |
| COMPLETED | 終了 | — |
| CANCELLED | 開始前に全員が抜けた | — |

TEAM_CONFIRMATION と SIMULATION は節ごとに繰り返す（2人＝1節、3人・4人＝3節）。

## 2. チンチロ（仕様書 3）

- 役の強さ：ピンゾロ（1-1-1）＞ シゴロ（4-5-6）＞ ゾロ目（6-6-6 が最強）＞ 通常役（2つ同じ目＋残りの目、残りの目が大きいほど強い）＞ ヒフミ（1-2-3）＞ 役なし
- 役が出たらその人は確定。3投しても役がなければ役なし（最下位扱い）
- 完全に同じ結果の人は、その人たちだけで再勝負（何度でも）
- サイコロはタップした瞬間にサーバーが決める（暗号論的な乱数）。全員がそろうまで出目は見えない。画面の物理演算（重力・摩擦・衝突）は演出だけで、最後に必ずサーバーの出目で止まる

## 3. カードプールと指名（仕様書 4・5）

- 枚数：11×人数＋12（4人＝56、3人＝45、2人＝34）。全員に同じカード
- ポジション：全員のフォーメーションが必要とする GK・DF・MF・FW の人数＋予備（GK2・DF4・MF4・FW2）
- レアリティ：全カードと同じ割合、各レアリティ最低1枚
- 指名：手番・プールにある・指名済みでない・自分のフォーメーションでその種類がまだ必要、をサーバーで確認。同じカードはルームで1回だけ（D1 の一意制約でも防ぐ）
- 自動指名：足りない人数が多い種類（同じなら残りが少ない種類）から、その種類の空いている位置に合う一番強い選手

## 4. データ（マイグレーション `0010_draft_match.sql`）

| 表 | 内容 |
| --- | --- |
| draft_rooms | ルームの状態・人数・状態の履歴・開始と終了の時刻・シーズン |
| draft_participants | 参加者（席・フォーメーション・指名順・最終順位・勝点・レートの変化） |
| draft_dice_results | チンチロの全投（ラウンド・何投目・出目・役・自動か・再勝負か） |
| draft_card_pools | 共通カードプール |
| draft_picks | 指名（ルーム内で同じカードは1回：一意制約） |
| draft_teams | 各チーム（フォーメーション・11人・最後の配置） |
| draft_match_results | 各試合の結果（試合の詳細は既存の試合の表） |
| draft_rankings | ランキング（シーズンごとのレート・試合数・1位の回数） |
| draft_audit_logs | 拒否した操作（仕様書 10） |
| legacy_drafts・legacy_draft_picks | 以前のドラフトの記録（名前だけ変更、決定 81） |

## 5. API

| API | 内容 |
| --- | --- |
| `POST /api/draft-match/queue` | マッチング（自分の対戦中のルームがあればそれを返す） |
| `GET /api/draft-match/:id` | 今の状態 |
| `POST /api/draft-match/:id/leave` | 抜ける（開始前は席を空け、開始後はサーバーが操作） |
| `POST /api/draft-match/:id/action` | 操作（フォーメーション・振る・指名・配置・準備完了） |
| `POST /api/draft-match/:id/ticket`・`GET /:id/ws` | WebSocket（ゲームはこちらで操作） |
| `GET /api/draft-match/ranking`・`/me` | ランキングと自分のレート |

## 6. 確認

- 単体テスト：役の強さ・3投・再勝負の順位・サイコロの偏り、プール（人数・ポジション・レアリティ・除外）、指名の拒否、自動指名で全員がフォーメーションどおりになること（2〜4人・全フォーメーション）、総当たり、状態の移り変わり
- 結合テスト `npm run e2e:draft-match`：マッチング（4人で即開始・開始済みには入らない・抜けると CANCELLED）、フォーメーション（非公開・時間切れ 4-3-3）、プール（56枚・全員同じ・ポジション・レアリティ・D1）、チンチロ（二重に振れない・自動で振る・順位・再勝負・D1）、ドラフト（手番外・指名済み・ポジションが埋まっている・同じカードを同時に2回・再接続・自動指名・D1）、チーム確認（違うフォーメーションは拒否・配置と戦術の変更）、試合（6試合）、ランキング・報酬・状態の履歴・監査ログ、2人（待ち時間の後）、3人（途中で1人抜ける）
- ブラウザ：iPhone の大きさで2人のルームを最後まで（フォーメーション → チンチロの演出 → 指名順 → ドラフト → チーム確認 → 試合 → 結果 → ランキング）
