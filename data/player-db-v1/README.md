# FOOTBALL DRAFT — Fictional Player Database v1.0

- 300 fictional player records.
- Rarity counts: Common 120, Rare 90, Epic 54, Legendary 27, Icon 9.
- Display ratings: PAC, SHO, PAS, DRI, DEF, PHY (1–99).
- SIM-only detailed attributes are stored separately in `simulation_attributes.json`.
- Five reusable rarity templates and 300 player card PNGs.
- All players, clubs and leagues are fictional.
- Card portraits are generic stylized silhouettes, not unique character portraits.
- OVR ranges are balancing guides, not hard constraints.
- Seeded prototype dataset; validate match balance before production use.
